# Entregas

Cada equipo crea su carpeta copiando `equipo_ejemplo/` y le pone su nombre: `entregas/equipo_<nombre>/`.

| Archivo | Qué va |
|---|---|
| `equipo.md` | Integrantes |
| `dashboard.md` | Link al dashboard (Genie o Claude) y una captura |
| `speech.md` | Link al Scrollyteller y el texto final de los 5 momentos |
| `prompts.md` | Todos los prompts que usaron, en orden, tal cual los pegaron |

**Se evalúan el speech y el dashboard.** Los prompts se entregan para ver cómo llegaron a la respuesta.
